# ⚡ Termux LITE

### ✨ Unique to Termux LITE
- 🪶 **~4k Total SLOC:** Complete app UI, terminal engine, bootstrap installer, and settings in ~4,000 lines of code.
- 🚀 **100% Jetpack Compose:** Pure declarative Kotlin UI with zero XML layouts for rapid startup and low memory usage.
- 🔗 **Smart Link Tap:** Tap any URL type — `https`, `x.com`/`twitter.com` status (full tweet id), Markdown `[text](url)`, `(https://…)`, `<url>`, `www.`, `magnet:`, or `ssh://` — including links split across wrapped rows. Tapping the label text opens the href behind it.
- 🔤 **Live terminal fonts:** JetBrains Mono (no ligatures) is the default. Settings also has Intel One Mono, Hack, Inconsolata, Fira Mono, Source Code Pro, Ubuntu Mono, IBM Plex Mono, and the Android system mono. Changing the font applies immediately — no restart.
